Tagwright for macOS

The same rules, native on your Mac.

A SwiftUI port of Tagwright: the tagging pipeline, the library layout and the rules you already know — running in process on your Mac. No Docker, no Python, no browser tab.

Download for Mac0.5.0

Free · macOS 15 or later · native SwiftUI

Shared rules

The web app's decisions, in an app.

The UI and the rules follow the architecture decision records of the web version: FLAC tags with upper-case keys, status as steps, issues and missing, the bliss naming and layout, and the move-to-library behaviour with the cover recreated.

The tag editor, Discogs assignment, MusicBrainz search and lyrics editor all follow the same conventions, so an album looks the same whichever version of Tagwright you open.

All in process

No helper tools to install.

Dynamic range (TT DR), ReplayGain (EBU R128 — the web app's rsgain preset at −14 LUFS, true peak, clipping protection at −1 dBTP), lyrics from LRCLIB and filename rules all run inside the app. Chromaprint algorithm 2 fingerprints are computed natively too.

The library view keeps the template, watcher and index in one place, and CSV output is there when you need to take the data somewhere else.

Under the hood

One Swift binary

Own Vorbis-comment and FLAC picture reader and writer; MP3 (ID3v2.4) through a single audio-file seam; audio frames copied, never re-encoded.

Discogs token stored in the macOS Keychain. No secrets in files.

Install

Open it and go.

  1. Download Tagwright from the latest release and move the app to Applications.
  2. Choose your staging folder and library folder on first launch.
  3. Pick an album, assign a release and run the pipeline.

Requires macOS 15 or later. To build from source: ./build-app.sh produces build/Tagwright.app using just the Xcode command line tools.
